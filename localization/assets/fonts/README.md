# Arabic font for game packs

IBM Plex Sans Arabic, Regular and Bold, version 1.101, unmodified, from
[github.com/IBM/plex](https://github.com/IBM/plex). Copyright © 2017 IBM Corp.,
with Reserved Font Name "Plex", under the SIL Open Font License 1.1 (`OFL.txt`).

The pack builder puts these files into Ren'Py, Godot and Unreal packs, with
`OFL.txt` beside them, and Unity's TextMeshPro font bundle is built from the
Regular face. The license lets them be passed on with the packs, as long as the
license goes with them and the fonts aren't sold on their own. If they are ever
changed (subset, merged, renamed glyphs), the result can't be called "Plex".
